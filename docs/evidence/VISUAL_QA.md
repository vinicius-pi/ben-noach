# Visual QA — production Editorial Modernism

Inspected the captured `docs/evidence/*.png` set at 390×844, 768×1024, and 1440×1000.

## Verdict

The reader still looks like a typeset book. Scripture is document text. Understand is a small verse-number control, not a giant button around the Hebrew.

| Surface | Mobile | Tablet | Desktop |
| --- | --- | --- | --- |
| Home | Cover, navy mark, Begin reading | Same, wider measure | Full cover plus library/path/trust bands |
| Reader | Hebrew display, JPS under it, small blue verse numbers | Same | Same, generous measure |
| Verse selected | `UNDERSTAND` hint + navy inset mark | Same | Same |
| Understand | Bottom sheet, Close outside the mode group | Bottom sheet | Study rail |
| Sources | Sheet switches to provenance / Siftei / Sefaria | Same | Rail |
| Enlarged | Type scale holds the measure | Same | Same |
| Hebrew off | English remains as a literary column | Same | Same |

## Verse affordance

Idle verses do not look like controls. The number is a quiet typographic mark. Selection reveals the Understand label; the Hebrew and English stay selectable text. That matches READ → UNDERSTAND rather than a list of buttons.

Desktop full-page screenshots stitch a tall reading column next to a viewport-tall rail, so the rail can appear “below” the verses in the PNG even though it is a second grid column in the browser.

Human review of snapshot diffs is still required before treating them as design approval.
