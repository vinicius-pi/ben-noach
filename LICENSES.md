# Licensing and third-party rights

This repository contains two legally distinct classes of material:

1. **software and original project documentation/editorial work**;
2. **third-party sacred/classical texts, translations, fonts, media, and metadata**.

A single software license must never be interpreted as relicensing third-party textual content.

## Current repository status

The final license for original project code has not yet been selected. Choose it deliberately before public production release and before accepting external code contributions.

## Third-party texts

Every bundled or cached textual version must have a machine-readable manifest entry containing its source/provider, version title, rights/license status, attribution requirements, and whether bundling is permitted.

Availability through Sefaria or another library does not by itself establish permission to redistribute a particular translation/version.

Where rights are unclear, prefer a link/deep-link rather than reproduction.

## Fonts

Only bundle fonts whose licenses permit the intended web/app distribution. Record font source and license in the source/asset manifest.

## Design references

Commercial editions and applications such as ArtScroll, Koren, ALHATORAH and other readers may be studied as product/editorial references. Their copyrighted text, illustrations, layouts, branding, and proprietary fonts are not project assets unless separately licensed.

## Future governance

If the repository is transferred to a rabbinic or nonprofit organization, preserve all third-party attribution/license metadata during the transfer.
